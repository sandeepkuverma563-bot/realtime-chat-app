# 💬 Real-Time Chat Application

A full-stack real-time messaging application built using the **MERN Stack** and **Socket.IO**.
The platform enables instant communication with secure authentication, online user status, image sharing, and a responsive modern UI.

---

# 🚀 Features

* 🔐 JWT Authentication & Authorization
* 💬 Real-Time Messaging with Socket.IO
* 🟢 Online/Offline User Status
* 🖼️ Image Sharing with Cloudinary
* 🍪 Secure HTTP-only Cookies
* 🔒 Password Hashing using bcrypt
* 📱 Fully Responsive UI
* ⚡ Fast and Scalable MERN Architecture

---
